# Code of conduct

The lt-suite community adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by reference under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Its pledge, standards, responsibilities, scope, and enforcement guidelines apply to this project's community spaces.
The upstream Covenant supplies the policy text; this file specifies the project's reporting route.

Report misconduct privately to **dorsaltegmentum**, the project maintainer.
Open a [private security advisory](https://github.com/dorsaltegmentum/lt-suite/security/advisories/new) titled **Conduct report**.
Include the incident, affected community space, and any evidence you may share privately.
Maintainers apply the Covenant's correction, warning, temporary-ban, and permanent-ban guidelines.
Use GitHub's **Report abuse** controls separately when platform enforcement is needed.
